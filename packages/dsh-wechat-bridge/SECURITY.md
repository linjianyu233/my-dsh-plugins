# Security Policy / 安全策略

## 支持的版本

| 版本 | 支持情况 |
|---|---|
| 1.x | ✅ 支持（安全修复随最新版本发布） |

## 报告漏洞

如果你发现安全漏洞，请**私下**报告，不要在公开 issue 中披露可复现细节：

1. 首选：GitHub 仓库 **Security** 选项卡 → **Report a vulnerability**（私有漏洞报告）；
2. 若仓库未启用该功能：新开一个 issue，标题以 `[SECURITY]` 开头，正文只描述影响范围与联系方式（**不要**贴 token、复现脚本或敏感数据），等待作者私下联系。

作者会在 7 天内确认，并在修复发布后再公开细节。

小问题（文档错误、拼写、一般 bug）请直接走普通 issue。
